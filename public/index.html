01 / 选好图案

从小尺寸开始

16 × 16 适合小挂件。用模板直接创作，也可以上传图片，按当前画布尺寸转换成内置色板。非正方形图片会完整居中保留，空白处不放拼豆。

02 / 一颗一颗

照着图纸摆豆

准备同一规格的拼豆和底板，参照图纸色号与材料数量摆放。画笔、橡皮、填色和取色让调整更轻松。图纸为 PNG，可打印；底板布局由实际尺寸决定。

03 / 完成作品

熨烫与定型

由成人按拼豆厂商说明操作熨斗，使用熨烫纸，避免直接接触塑料。冷却定型后再取出，可加上挂链。

让创作更顺手

B 画笔 · E 橡皮 · F 填色 · I 取色 · Ctrl / ⌘ + Z 撤销 · Ctrl / ⌘ + Shift + Z 重做 · Ctrl / ⌘ + S 保存

画布支持鼠标、触屏与键盘。聚焦画布后用方向键移动，空格放置拼豆。草稿自动保存，作品可导出 JSON 并在其他设备重新导入。

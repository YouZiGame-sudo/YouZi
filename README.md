# YouZi · 拼豆工作室

可直接运行的拼豆创作 V1。原生 JavaScript ES Modules + Canvas 2D + CSS，Node.js 提供开发服务和静态构建；没有第三方运行依赖，无需账号、API Key 或安装依赖。

## 启动

安装 Node.js 20 或更高版本，在项目根目录执行：

```sh
npm start
```

打开 **http://localhost:3000**。Windows、macOS 与 Linux 启动方式一致。`npm run dev` 与启动命令相同，修改后刷新浏览器。不要直接双击 HTML：ES Modules 需要 HTTP 服务。

可通过 `PORT` 调整端口，`HOST` 调整绑定地址。默认仅监听本机 `127.0.0.1`。如需手机在同一局域网体验，设置 `HOST=0.0.0.0`，用电脑局域网 IP 访问，并按系统需要开放端口。

```sh
# macOS / Linux
HOST=0.0.0.0 PORT=3000 npm start
# Windows PowerShell
$env:HOST='0.0.0.0'; npm start
```

## V1 能做什么

- **创作台**：小花、小猫、爱心模板；16 / 24 / 32 / 48 / 64 格画布；尺寸调整保留图案，可撤销。
- **编辑器**：鼠标与触屏连续绘图、橡皮、四邻域填色、取色；最多 60 次操作历史；网格与缩放。
- **图片转拼豆**：PNG / JPEG / WebP，最大 20 MB；图像等比居中保留，按当前画布尺寸采样，映射为 16 色内置色板，透明像素保留为空。
- **材料**：实时颜色数量、总颗数；CSV 清单包括建议多备 10% 的用量。
- **作品集**：命名、保存、重新打开、确认删除；自动保存当前草稿并在刷新后恢复。
- **导出与导入**：带网格、坐标、每格色号与材料清单的 PNG 图纸；可编辑 JSON 文件可跨设备备份和导入。
- **指南 / 本地信息**：实际操作说明、快捷键、存储说明。
- **视觉**：奶油白、松绿、杏色；圆润面板、柔和阴影、按压反馈、页面过渡；响应式布局及减少动画偏好支持。

## 使用流程

1. 选择模板，或选择尺寸后上传图片。
2. 用画笔与填色调整，点击色板切换颜色。
3. 修改名称，点击「保存作品」收入作品集。
4. 导出 PNG 图纸与 CSV 材料表；导出 JSON 做备份。

快捷键：`B` 画笔、`E` 橡皮、`F` 填色、`I` 取色、`Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Shift+Z` 重做、`Ctrl/⌘+S` 保存。画布可用 Tab 聚焦，方向键移动，空格绘制。输入框内不会触发绘图快捷键。

## 数据与边界

所有图片转换、编辑和导出均在浏览器执行；服务器只提供静态文件。`localStorage` 按浏览器和站点来源保存作品与草稿；没有云同步或账户系统。换设备、换端口/域名或清理站点数据后不会自动出现原作品，请提前导出 JSON。存储失败会提示导出备份。

色号 A01–E03 是 **YouZi 内置色号，非 MARD / Hama 等品牌编号**。尚未校准实体拼豆色卡；图片屏幕色差和 16 色量化会影响还原效果。图纸打印需要按实际底板调节比例，不承诺一比一物理尺寸。

优先使用现代 Chrome、Edge、Safari、Firefox；需要 Canvas 2D、Pointer Events、dialog、createImageBitmap、structuredClone 等浏览器能力。触屏布局已实现，但实际设备手感仍需用户试用校准。

## 验证与部署

```sh
npm run check
npm test
npm run build
```

`dist/` 可部署到任意静态服务器、GitHub Pages 或其他静态托管平台。资源采用相对路径，支持仓库子目录。无需服务端数据库。GitHub Actions 自动执行检查、测试和构建；尚未配置自动部署。开发服务器用于本地开发；公开发布使用支持 HTTPS 的静态托管服务。

程序验证涵盖色板精确匹配、透明像素、连通填色边界、连续线段、缩放、模板、恶意/异常 JSON 校验、HTTP 文件响应与路径边界、构建一致性。浏览器视觉及真实触屏验证应另行进行，不能用纯逻辑测试替代。

## 后续迭代入口

1. `public/core.js`：可配置品牌色板、感知色差量化、减少颜色数、抖动选项。
2. `public/app.js`：裁剪与图片转换预览、图层/选区、IndexedDB 大容量存储。
3. `public/style.css`：主题 token 与实机手感校准，移动端底部工具栏。
4. 图纸输出：PDF、多底板分页、品牌编号映射、按实际珠径输出。
5. 独立服务端模块：登录、云同步、共享作品；V1 无任何假登录或虚拟支付流程。
6. 移动端封装 / PWA：离线缓存与安装体验，保留同一编辑核心。
